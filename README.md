AI-Powered Due Diligence & Investment Memo Generator

This repository contains an AI-powered analyst agent developed for MobilityX Africa / Fundie Ventures, designed to support venture capital due diligence for early-stage mobility, logistics, and infrastructure startups, particularly across Africa and emerging markets.

The agent automates the transformation of raw startup materials—pitch decks, financials, and external research—into structured, investment-grade outputs aligned with MobilityX’s internal evaluation frameworks.
